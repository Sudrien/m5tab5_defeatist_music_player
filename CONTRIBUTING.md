## Contributing

- It is assumed that actual human programmers will never care to contribute to this, beyond directing an LLM.

- Make a fork, commit your changes, and make a pull request from that. If there is only one commit for multiple features, it will be rejected.
- If you can't be bothered to learn Git, [Download the master zip](https://github.com/Sudrien/m5tab5_defeatist_music_player/archive/refs/heads/main.zip), and ask your AI to create a series of git am-able .patch(es) off that, and create an issue with those patch(es). If there is only one patch for multiple features, it will be rejected.
